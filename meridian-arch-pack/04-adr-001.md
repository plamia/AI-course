# ADR-001: Adopt Headless Commerce Architecture via commercetools for Unification

## Status
Accepted

## Owner
Architecture Team

## Source and Freshness
- **Source:** Meridian Case A brief; CTO Strangler-Fig mandate; Module 300 Design outputs.
- **Last Reviewed:** 2026-09-26
- **Status:** Accepted

## Review Trigger
Re-evaluate if commerce vendor licensing, multi-region scaling limits, or enterprise extensibility requirements fundamentally change.

## Context
Meridian operates 22 regional e-commerce stacks (Shopify, bespoke .NET, Magento) causing fragmented customer experiences, isolated loyalty accounts, and ~7% phantom-stock cancellations. The CTO mandates a strangler-fig migration without downtime across 1,400 stores.

## Decision
We will adopt **commercetools** as the enterprise headless commerce backbone for all unified capabilities (identity, cart, checkout, catalog). Regional storefronts will gradually decouple their frontends and integrate with commercetools APIs via an API Gateway.

## Alternatives Considered
1. **Consolidate onto Shopify Plus (Single SaaS):** Rejected because Shopify's closed-box checkout and native architecture cannot be sufficiently customized to support complex multi-region payment flows (e.g., Italian Postepay, Japanese PayPay) and direct in-store POS inventory integration across 1,400 stores.
2. **Build a Custom Monolithic Commerce Engine:** Rejected because building and maintaining a custom multi-tenant commerce engine violates the 18-month timeline and $42M budget constraint, introducing massive ongoing engineering overhead.

## Consequences
- **Positive:** Decouples frontend UX from core commerce logic; enables incremental strangler-fig migration across 22 regions; robust API-first architecture.
- **Negative:** Requires API gateway management; engineering teams must adapt to headless architectural patterns.

## Agent-Readable Summary
All new unified commerce capabilities (cart, checkout, catalog) MUST use commercetools APIs via the Apollo API Gateway. Do not build custom commerce monoliths or integrate regional storefronts directly to legacy databases.
